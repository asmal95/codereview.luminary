# Исправление: Кракозябры в настройках (Encoding Issue)

## Проблема

При открытии настроек расширения (Options), русский текст в дефолтном промпте "AI Explain Prompt" отображался как кракозябры:

```
Ð¢Ñ‹ Ð¿Ð¾Ð»ÐµÐ·Ð½Ñ‹Ð¹ AI Ð°ÑÑÐ¸ÑÑ‚ÐµÐ½Ñ‚. Ð¢Ð²Ð¾Ñ Ð·Ð°Ð´Ð°Ñ‡Ð° - Ð¾Ð±ÑŠÑÑÐ½Ð¸Ñ‚ÑŒ...
```

Вместо:
```
Ты полезный AI ассистент. Твоя задача - объяснить...
```

## Причина

В файле `public/options.html` отсутствовал мета-тег `<meta charset="UTF-8">`.

Без этого тега браузер использует кодировку по умолчанию (обычно ISO-8859-1 или Windows-1252), которая не поддерживает кириллицу. В результате UTF-8 символы интерпретируются неправильно.

## Решение

Добавлен `<meta charset="UTF-8">` в секцию `<head>` файла `options.html`:

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>OpenAI API Key</title>
    ...
```

## Технические детали

### Почему это важно?

**UTF-8** - это универсальная кодировка, поддерживающая все символы Unicode, включая:
- Кириллицу (русский, украинский, и т.д.)
- Латиницу
- Китайские иероглифы
- Эмодзи
- И многое другое

Без явного указания `<meta charset="UTF-8">`, браузер может:
1. Использовать системную кодировку по умолчанию
2. Попытаться угадать кодировку (часто неправильно)
3. Отобразить символы некорректно

### Почему работало в content.js?

Content script инжектируется в существующую страницу, которая обычно уже имеет правильную кодировку. Options page - это отдельная HTML страница расширения, которая должна сама декларировать кодировку.

## Best Practices

### Всегда добавляйте charset в HTML:

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <!-- Остальные мета-теги и стили -->
  </head>
```

### Порядок мета-тегов:

Хорошая практика - размещать `<meta charset="UTF-8">` **первым** в `<head>`, до других мета-тегов и тайтла:

```html
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="...">
  <title>Page Title</title>
  ...
</head>
```

### Проверка кодировки файлов

Убедитесь, что все исходные файлы сохранены в UTF-8:

**В VS Code:**
- Смотрите в правом нижнем углу: должно быть "UTF-8"
- Если нет, кликните и выберите "Save with Encoding" → "UTF-8"

**В других редакторах:**
- Обычно есть настройка "File Encoding"
- Выбирайте "UTF-8" или "UTF-8 without BOM"

## Дополнительная информация

### Что такое эти символы?

`Ð¢Ñ‹` - это результат интерпретации UTF-8 байтов как ISO-8859-1:
- UTF-8: `Ты` = байты `0xD0 0xA2 0xD1 0x8B`
- ISO-8859-1 интерпретирует каждый байт как символ: `Ð¢Ñ‹`

### Почему `meta charset` важнее, чем HTTP заголовок?

Для локальных файлов (расширения) нет HTTP сервера, который мог бы отправить заголовок `Content-Type: text/html; charset=UTF-8`. Поэтому мета-тег критически важен.
