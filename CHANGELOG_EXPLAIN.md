## 🔧 Сборка и тестирование

### Сборка
```bash
npm run build
```

### Установка
1. Откройте `chrome://extensions`
2. Нажмите кнопку "Обновить" для расширения
3. Или: "Загрузить распакованное расширение" → выберите папку `build`

### Тестирование
1. Откройте любую веб-страницу
2. Выделите текст
3. Правый клик → "Объяснить с помощью AI"
4. Проверьте работу окна, drag, resize
5. Добавьте вопрос и нажмите "Объяснить"
6. Проверьте streaming ответ

## 👨‍💻 Технические детали реализации

### Архитектура решения

```
User Action (Select Text + Right Click)
    ↓
Context Menu Event (background.js)
    ↓
chrome.runtime.sendMessage({action: 'explainText', text: ...})
    ↓
Content Script (content.js)
    ↓
FloatingExplainWindow.show(text)
    ↓
User adds question (optional)
    ↓
callChatGPT via streaming API
    ↓
Real-time UI updates
```

### Преимущества подхода

✅ **Модульность** - независимый класс, не влияет на существующий код  
✅ **Переиспользование** - использует существующую streaming инфраструктуру  
✅ **Расширяемость** - легко добавить новые функции  
✅ **UX** - плавающее окно не блокирует страницу  
✅ **Performance** - минимальное влияние на производительность
