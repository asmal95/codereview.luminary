## 🚀 Как запустить

### Шаг 1: Соберите расширение
```bash
cd e:\projects\codereview.gpt
npm run build
```

### Шаг 2: Обновите расширение в браузере
1. Откройте `chrome://extensions`
2. Найдите **codereview.luminary**
3. Нажмите кнопку **"Обновить"** (🔄)

### Шаг 3: Протестируйте!
1. Откройте любую веб-страницу (например, GitHub)
2. Выделите текст (код, документацию, что угодно)
3. Правый клик → **"Объяснить с помощью AI"**
4. Наслаждайтесь! 🎉

## 🎯 Технические особенности

### Что работает "из коробки"
✅ Streaming API - использует существующую инфраструктуру  
✅ Все API поддержаны - OpenAI, Ollama, LM Studio, и др.  
✅ Кэширование - не нужно, каждый запрос уникальный  
✅ Обратная совместимость - не ломает существующий код  
✅ Независимость - работает параллельно с Code Review окном

### Безопасность
✅ API ключи хранятся в chrome.storage.sync (зашифровано)  
✅ Background script изолирован от страницы  
✅ Content script не имеет прямого доступа к ключам  
✅ Все запросы проходят через background script
