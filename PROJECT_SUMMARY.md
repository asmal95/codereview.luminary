# Саммари проекта codereview.gpt

## Общее описание

**codereview.gpt** — это расширение для браузера Chrome, которое автоматически анализирует Pull Request'ы на GitHub и Merge Request'ы на GitLab с помощью ChatGPT (OpenAI API). Расширение помогает разработчикам получать код-ревью от ИИ, выявляя баги, проблемы безопасности и нарушения best practices.

### Основные возможности:
- Автоматический анализ изменений кода в PR/MR
- Поддержка GitHub и GitLab (включая self-hosted)
- Интеграция с OpenAI API (ChatGPT)
- Кэширование результатов для быстрого доступа
- Красивый UI с использованием Tailwind CSS

### Версия: 0.3.0

## Основные файлы проекта

### 1. **package.json**
**Назначение:** Конфигурация npm-проекта, зависимости и скрипты сборки.

**Ключевые зависимости:**
- `chatgpt` (^5.1.3) — библиотека для работы с ChatGPT API
- `parse-diff` (^0.11.1) — парсинг diff-файлов
- `node-html-parser` (^6.1.5) — парсинг HTML
- `showdown` (^2.1.0) — конвертация Markdown в HTML
- `tailwindcss` (^3.2.4) — CSS-фреймворк для стилизации

**Скрипты:**
- `npm run build` — сборка для production
- `npm run watch` — сборка в режиме разработки с watch
- `npm run format` — форматирование кода с Prettier

---

### 2. **public/manifest.json**
**Назначение:** Манифест расширения Chrome (Manifest V3).

**Ключевые параметры:**
- **permissions:** `activeTab`, `storage`, `scripting` — для доступа к вкладкам, хранилищу и выполнения скриптов
- **host_permissions:** доступ к GitHub и GitLab для загрузки patch-файлов
- **action:** настройка popup-окна расширения
- **options_ui:** страница настроек для ввода API ключа

---

### 3. **src/popup.js** ⭐ (Главный файл)
**Назначение:** Основная логика работы расширения.

**Основные функции:**

- **`run()`** — точка входа:
  - Определяет текущую вкладку
  - Определяет провайдера (GitHub/GitLab)
  - Извлекает URL PR/MR
  - Проверяет кэш результатов
  - Запускает ревью при необходимости

- **`reviewPR(diffPath, context, title)`** — основная функция ревью:
  - Загружает patch-файл с изменениями
  - Парсит diff с помощью `parse-diff`
  - Фильтрует бинарные файлы и lock-файлы
  - Разбивает большие изменения на части (лимит ~15384 символов)
  - Формирует промпты для ChatGPT
  - Отправляет запросы в ChatGPT с прогресс-обновлениями
  - Отображает результат в формате Markdown

- **`callChatGPT(messages, callback, onDone)`** — взаимодействие с API:
  - Получает API ключ из хранилища
  - Создает экземпляр ChatGPTAPI
  - Отправляет сообщения последовательно
  - Обрабатывает прогресс-обновления
  - Обрабатывает ошибки

- **`inProgress(ongoing, failed, rerun)`** — управление UI-состоянием:
  - Показывает спиннер во время обработки
  - Показывает статус (успех/ошибка)
  - Управляет видимостью кнопки "run again"

**Особенности:**
- Поддержка GitHub и GitLab (включая self-hosted)
- Кэширование результатов в `chrome.storage.session`
- Обработка больших изменений через разбиение на части
- Прогрессивное отображение ответа от ChatGPT

## Алгоритм работы расширения

1. **Пользователь открывает PR/MR** на GitHub или GitLab
2. **Клик по иконке расширения** → открывается popup
3. **Расширение определяет провайдера:**
   - Анализирует URL вкладки
   - Для GitLab проверяет наличие meta-тега
4. **Извлечение данных:**
   - URL patch-файла (`.patch` для GitLab, специальный URL для GitHub)
   - Описание PR/MR (через `chrome.scripting.executeScript`)
   - Заголовок PR/MR
5. **Проверка кэша:**
   - Если результат есть в `chrome.storage.session` → показывается сразу
   - Иначе запускается ревью
6. **Процесс ревью:**
   - Загрузка patch-файла
   - Парсинг diff
   - Фильтрация бинарных и lock-файлов
   - Разбиение на части при необходимости
   - Формирование промптов для ChatGPT
   - Последовательная отправка промптов в ChatGPT
   - Прогрессивное отображение ответа
7. **Сохранение результата** в кэш для быстрого доступа

## Технические детали

### Обработка больших изменений
- Лимит на часть: ~15384 символов (примерно 4096 токенов минус запас)
- Большие файлы разбиваются на части
- Каждая часть отправляется отдельным сообщением
- Показывается предупреждение о возможной неполноте ревью

### Безопасность
- API ключ хранится в `chrome.storage.sync` (синхронизируется между устройствами)
- Результаты ревью хранятся в `chrome.storage.session` (только для текущей сессии)
- Используется Manifest V3 с ограниченными разрешениями

### Поддерживаемые платформы
- GitHub (github.com)
- GitLab SaaS (gitlab.com)
- GitLab self-hosted (определяется по meta-тегу)
