# 🚀 Быстрый старт - Функция "Объяснить с помощью AI"

## За 3 простых шага

### 1️⃣ Выделите текст
Выделите любой текст на веб-странице, который хотите объяснить.

### 2️⃣ Правый клик → "Объяснить с помощью AI"
![Context Menu](https://via.placeholder.com/400x200/667eea/ffffff?text=Right+Click+→+Explain+with+AI)

### 3️⃣ Получите ответ
- (Необязательно) Добавьте свой вопрос
- Нажмите "Объяснить" или **Ctrl+Enter**
- Наслаждайтесь streaming ответом в реальном времени! 🎉

## ⚙️ Настройка (только при первом использовании)

1. Кликните правой кнопкой по иконке расширения
2. Выберите **"Параметры"** или **"Options"**
3. Введите ваш **OpenAI API Key** (или настройте локальную модель)
4. Нажмите **"Сохранить"**

### Локальные модели (без API ключа)
Для Ollama:
- **API Base URL:** `http://localhost:11434/v1`
- **Model:** `qwen3-coder:30b` (или другая модель)

### 🆕 Кастомизация промптов (опционально)
Вы можете настроить, **как AI объясняет текст**:

1. В Options прокрутите до **"AI Explain Prompt"**
2. Отредактируйте промпт под свои нужды
3. Используйте переменные: `{text}` и `{question}`
4. Save

**Примеры:**
- Для новичков: "Объясняй просто, без жаргона"
- Для экспертов: "Технический deep dive с complexity analysis"
- Для безопасности: "Анализируй на уязвимости OWASP"

📚 См. [CUSTOM_PROMPTS.md](CUSTOM_PROMPTS.md) для готовых примеров

## 🆘 Не работает?

### Проверьте:
1. ✅ API ключ настроен в параметрах расширения
2. ✅ Страница перезагружена после установки/обновления
3. ✅ Расширение активно (иконка в панели инструментов)

### Отладка:
1. Нажмите **F12** на странице
2. Откройте вкладку **Console**
3. Ищите сообщения с префиксом `[CS]` или `[BG]`
